Configuration Guidelines
Common Configuration Names:
  • rate_per_km - Cost per kilometer (e.g., "0.25")
  • cartrack_username - CarTrack API username
  • cartrack_password - CarTrack API password
  • investec_client_id - Investec API client ID
  • investec_secret_key - Investec API secret
  • investec_api_key - Investec API key
  • default_registration - Default vehicle registration
Security Tips:
  • Never store sensitive data in plain text in production
  • Use AWS Secrets Manager for production credentials
  • Regularly rotate API keys and passwords
  • Monitor access logs for unauthorized changes
Value Formats:
  • String: Plain text values
  • Number: 0.25, 100, -5.5
  • Boolean: true, false
  • JSON: {"key": "value"}
